# ZeroSoleil FMCG landing page

Static, responsive product introduction. Product features are labelled as planned and the example is explicitly illustrative. No external dependencies, forms, tracking, or unconfigured email addresses.

## Publish with GitHub Pages

Upload `index.html` and `.nojekyll` to the root of a public repository. Under Settings → Pages, choose Deploy from a branch → main → / (root) → Save.

## Connect your domain

After the GitHub Pages URL works, enter your domain in Settings → Pages → Custom domain. Follow GitHub's current DNS instructions and enable Enforce HTTPS after the certificate is ready. No CNAME is included here, so the default GitHub Pages address works before domain setup.

## Contact email

Once the domain email has been configured and tested, add a real contact address to the landing page. There is intentionally no unverified contact address or inactive signup form.
